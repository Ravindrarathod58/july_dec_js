QUICK REFERENCE
---------------
Create an object    :  let student = { name: "Asha", marks: 85 };
Read a property     :  student.name        or   student["name"]
Dynamic property    :  let key = "marks";  student[key]
Add / update        :  student.city = "Pune";   student.marks = 90;
Delete a property   :  delete student.city;
Check a property    :  "marks" in student        (true or false)
Loop over an object :  for (let key in student) { console.log(key + " : " + student[key]); }
Nested object       :  employee.address.city
Array in an object  :  student.marks[0]
Array of objects    :  students[0].name
