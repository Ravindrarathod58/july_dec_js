==============================================================
JAVASCRIPT PRACTICE ASSIGNMENTS
TOPIC: FUNCTION TYPES (NAMED, EXPRESSION, ARROW)
==============================================================

THE THREE TYPES (for reference)
-------------------------------
Named function (declaration) :  function add(a, b) { return a + b; }
Function expression          :  const add = function (a, b) { return a + b; };
Arrow function               :  const add = (a, b) => a + b;
