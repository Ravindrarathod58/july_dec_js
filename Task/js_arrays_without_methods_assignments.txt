##############################################################
PART 1: ARRAY BASICS
##############################################################

--------------------------------------------------------------
Q1. Write a program in JavaScript to read n numbers into an array and display them.
--------------------------------------------------------------
-> Declare an empty array.
-> Read the number of elements n.
-> Using a loop, read n numbers and store each number in the array by index.
-> Using another loop, display all the elements of the array.

Sample input :
Input number of elements : 5
Input 5 elements : 10 20 30 40 50

Sample output : The elements of the array are : 10 20 30 40 50


--------------------------------------------------------------
Q2. Write a program in JavaScript to find the sum and average of the elements of an array.
--------------------------------------------------------------
-> Read n and then read n numbers into an array.
-> Using a loop, add all the elements to find the sum.
-> Calculate the average as sum divided by the number of elements (use arr.length).
-> Print the sum and the average.

Sample input :
Input number of elements : 5
Input 5 elements : 10 20 30 40 50

Sample output :
Sum of elements : 150
Average of elements : 30


--------------------------------------------------------------
Q3. Write a program in JavaScript to display the elements of an array in reverse order.
--------------------------------------------------------------
-> Read n and then read n numbers into an array.
-> Using a loop that starts from the last index and goes down to 0, build the output string.
-> Do not change the original array and do not use reverse().
-> Print the output string.

Sample input :
Input number of elements : 5
Input 5 elements : 10 20 30 40 50

Sample output : The array in reverse order : 50 40 30 20 10


--------------------------------------------------------------
Q4. Write a program in JavaScript to find the largest and smallest elements of an array.
--------------------------------------------------------------
-> Read n and then read n numbers into an array.
-> Assume the first element is both the largest and the smallest, then compare it with the remaining elements using a loop.
-> Do not use Math.max() or Math.min().
-> Print the largest and the smallest element.

Sample input :
Input number of elements : 5
Input 5 elements : 45 12 78 3 56

Sample output :
Largest element : 78
Smallest element : 3


--------------------------------------------------------------
Q5. Write a program in JavaScript to count the even and odd numbers in an array.
--------------------------------------------------------------
-> Read n and then read n numbers into an array.
-> Using a loop, check each element and increase the even counter or the odd counter.
-> Print both counts.

Sample input :
Input number of elements : 5
Input 5 elements : 12 7 20 15 8

Sample output :
Even numbers : 3
Odd numbers : 2

Q11. Write a program in JavaScript to insert an element at a given position of an array.
--------------------------------------------------------------
-> Read n, then read n numbers into an array.
-> Read the index (position) and the value to insert.
-> Create a second empty array. Using loops, copy the elements before the position, store the new value, then copy the remaining elements.
-> Do not use splice(), push() or unshift().
-> Print the new array.

Sample input :
Input number of elements : 5
Input 5 elements : 10 20 30 40 50
Input index to insert at : 2
Input value to insert : 25

Sample output : Array after insertion : 10 20 25 30 40 50

Q12. Write a program in JavaScript to delete an element at a given position of an array.
--------------------------------------------------------------
-> Read n, then read n numbers into an array.
-> Read the index of the element to delete.
-> Create a second empty array. Using a loop, copy every element except the one at the given index.
-> Do not use splice(), pop() or shift().
-> Print the new array.

Sample input :
Input number of elements : 5
Input 5 elements : 10 20 30 40 50
Input index to delete : 1

Sample output : Array after deletion : 10 30 40 50

Q13. Write a program in JavaScript to reverse an array in the same array without using reverse().
--------------------------------------------------------------
-> Read n, then read n numbers into an array.
-> Print the original array.
-> Using a loop that runs up to half of the array, swap the first element with the last, the second with the second last, and so on. Use a temporary variable for swapping.
-> Do not create a second array.
-> Print the reversed array.

Sample input :
Input number of elements : 5
Input 5 elements : 1 2 3 4 5

Sample output :
Original array : 1 2 3 4 5
Reversed array : 5 4 3 2 1

Q14. Write a program in JavaScript to copy an array into another array using a loop.
--------------------------------------------------------------
-> Read n, then read n numbers into an array called original.
-> Create an empty array called copy and fill it using a loop, element by element.
-> Print both arrays.
-> Change the first element of copy to 99 and print both arrays again to show that original is not affected.

Sample input :
Input number of elements : 3
Input 3 elements : 10 20 30

Sample output :
Original array : 10 20 30
Copied array : 10 20 30
After changing the first element of the copy :
Original array : 10 20 30
Copied array : 99 20 30

--------------------------------------------------------------
-> Read the size and elements of the first array.
-> Read the size and elements of the second array.
-> Create a third empty array. Using loops, copy all elements of the first array and then all elements of the second array into it.

-> Print the merged array.

Sample input :
Input size of first array : 3
Input 3 elements : 1 2 3
Input size of second array : 4
Input 4 elements : 4 5 6 7

-> Do not use sort().
-> Print the sorted array.

--------------------------------------------------------------

Input number of elements : 6

--------------------------------------------------------------

-> Find the hottest day, the coldest day and the number of days with a temperature above the weekly average.
-> Use the index of the temperature to get the matching day name.
-> Print the results.

Sample input : Input 7 temperatures : 32 35 30 28 36 33 31

Hottest day : Friday (36 degrees)
Coldest day : Thursday (28 degrees)
Days above average : 3
